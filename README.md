# App de limpieza de habitaciones

Aplicación web responsive (PWA) para registrar y verificar la limpieza de habitaciones de hoteles y alquileres vacacionales: foto de entrada, reporte de daños, tiempo medido y foto de salida, con roles de administrador, supervisor y empleado.

- `CLAUDE.md` — contexto y decisiones del proyecto.
- `docs/especificacion/` — especificación completa (LaTeX para Overleaf y PDF).
- `backend/` — API en Python (FastAPI). Pendiente (fase 2).
- `frontend/` — aplicación en React + TypeScript + Vite. Pendiente (fase 3).
